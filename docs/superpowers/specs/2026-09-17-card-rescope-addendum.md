## 왜 추가 수집인가

Plan 1의 카드 94장은 "가성비 먹방·술 + 범용 쇼핑" 기준으로 모았다.
사용자가 기준을 바꿨다:

1. **음식** — 구글 평점 상위, 도톤보리 근방 집중
2. **쇼핑** — 남성 브랜드 의류, 일본 감성, 엔저 이점

기존 음식·술 카드는 유지한다(기준이 다를 뿐 유효하다). **쇼핑 22장은
사실상 교체 대상**이다 — 돈키호테·요도바시·유니클로·파르코 같은 범용
카드라 브랜드 쇼핑 기준에 거의 걸리지 않고, 그중 18장은 이미
`⚠ 미검증` 상태다.

## A. 음식 — 구글 평점 기준 재수집

### A.1 스키마 추가

카드에 두 필드를 추가한다. 둘 다 음식·술 카드에만 적용.

```js
googleRating: 4.6,      // number. 소수 1자리
reviewCount: 1240,      // number. 리뷰 수
```

`validate-cards.mjs`에 검사를 추가한다:
- `googleRating`이 있으면 0.0~5.0 범위
- `reviewCount`가 있으면 양의 정수
- 둘 중 하나만 있으면 실패 (평점만 있고 표본 수가 없으면 판단 불가)

### A.2 수집 기준 — 사용자 확답 필요

사용자에게 셋 중 하나를 확인받고 시작한다. 확답 없이 임의로 정하지 말 것.

| 안 | 기준 | 예상 수확 | 비고 |
|---|---|---|---|
| 1 | 구글 4.8+ | 한 자릿수 | 요청 원안. 리뷰 수 적은 신규점이 섞임 |
| 2 | 구글 4.5+ & 리뷰 500+ | 20~30장 | 표본이 뒷받침되는 "검증된 맛집" |
| 3 | 타베로그 3.5+ | 30장+ | 현지 기준. 일본 식당은 이 지표가 더 신뢰도 높음 |

**왜 확인이 필요한가**: 구글 평점은 타베로그와 스케일이 다르다. 오사카
인기 식당 대부분이 구글 3.8~4.3에 몰려 있고, 4.8 이상은 리뷰 수가 적거나
특정 집단이 몰아준 경우가 많다. 리뷰 수 하한 없이 4.8만 걸면 표본 20개짜리
신규 가게가 노포보다 위로 올라온다.

### A.3 범위

- 지역: `dotonbori` 중심, 도보 10분 내 `uranamba`·`shinsaibashi`·`nipponbashi` 포함
- 기존 f-01~f-38과 중복되면 **새로 만들지 말고 기존 카드에 평점 필드를 채운다**
- 신규 카드 id는 `f-39`부터

### A.4 평점 수집의 알려진 난점

구글맵은 자동 조회를 차단한다. Plan 1에서 다수 카드가 "구글 평점 미확인"으로
남은 이유가 이것이다. 우회 수단을 먼저 정하고 들어갈 것:
- 구글맵 place 페이지의 og 메타데이터
- 타베로그·핫페퍼·Retty에 병기된 구글 평점
- 확보 실패 시 `googleRating`을 비우고 `caution`에 사유를 남긴다.
  **추정값을 쓰지 말 것** — Plan 1에서 조작된 데이터가 나온 전례가 있다.

## B. 쇼핑 — 남성 브랜드 재수집

### B.1 사용자 기준

- **대상**: 30대 후반 남성 4인
- **가격 상한**: 1점당 약 30만원 = **3만엔 이하** (환율은 조사 시점에 확인)
- **선별 축**: 엔저로 **한국 대비 가격 이점이 실제로 있는 것**
- **성격**: 일본 감성 — 일본 브랜드 또는 일본 한정 라인

### B.2 스키마 추가

쇼핑 카드에 추가:

```js
brands: ["THE NORTH FACE PURPLE LABEL", "nanamica"],  // 취급 브랜드
priceBand: "1.5만~3만엔",        // 이 매장에서 목표 품목의 실구매가
japanOnly: true,                  // 일본 한정/내수 전용 라인 취급 여부
whyCheaper: "한국 미전개 라인. 국내는 병행수입만 있고 웃돈이 붙음"
```

`whyCheaper`는 **추측 금지**. 한국 정식 전개 여부를 확인한 근거가 있을 때만
채우고, 없으면 빈 문자열로 두고 `caution`에 사유를 적는다.

### B.3 조사할 브랜드 후보

사용자가 든 예시: 노스페이스, 휴먼메이드, 포터.
아래는 **조사 대상 후보이지 확정 목록이 아니다.** 각 브랜드의 오사카 미나미권
매장 실재 여부를 반드시 확인하고, 없으면 버린다.

| 축 | 후보 |
|---|---|
| 일본 한정 아웃도어 | THE NORTH FACE PURPLE LABEL (nanamica 전개), Snow Peak, mont-bell |
| 스트리트 | HUMAN MADE, WTAPS, NEIGHBORHOOD, FreshService |
| 가방·소품 | PORTER / 吉田カバン, master-piece |
| 아메카지·데님 | Kapital, orSlow, Studio D'Artisan, Momotaro Jeans |
| 셀렉트숍 PB | BEAMS, UNITED ARROWS, SHIPS, JOURNAL STANDARD |
| 시계·잡화 | G-SHOCK 일본한정, SEIKO 일본한정 |

3만엔을 넘는 브랜드(visvim 등)는 제외한다.

### B.4 지역

미나미권에서 남성 셀렉트숍이 밀집한 곳은 **호리에 오렌지스트리트**다.
`taxonomy.json`의 `areas`에 `horie`가 없으므로 추가해야 한다.

- `horie` — 오렌지스트리트 일대 (신규 지역 키 추가 필요)
- `shinsaibashi` — 신사이바시스지·파르코·아메리카무라
- `umeda` — 한큐·그랜드프론트 (원정 시)

### B.5 기존 카드 처리

- s-01~s-15(돈키·드럭스토어·전자·범용 패션)는 **유지하되 우선순위를 낮춘다**.
  여행에서 소모품·기념품은 여전히 필요하다.
- s-09~s-15 중 브랜드 쇼핑 기준에 맞지 않는 카드는 교체 검토.
- 신규 카드 id는 `s-23`부터.
- 기존 `⚠ 미검증` 카드를 이번 조사에서 확인했으면 표시를 갱신한다.

## C. 공통 — Plan 1에서 실패했던 지점

이 조사는 아래를 반드시 지킨다. 전부 Plan 1에서 실제로 터진 것들이다.

1. **출처는 특정 페이지여야 한다.** `google.com/maps/search/?api=1&query=...`
   같은 조립 가능한 검색 URL은 증거가 아니다. 검증기가 거부한다.
2. **좌표는 300m 이내여야 한다.** `bun run check-coords`로 확인하고,
   초과분은 개별 판정 후 근거를 `docs/research/decisions/`에 남긴다.
3. **확인 못 한 것을 확인했다고 쓰지 않는다.** 미확인은 `caution`에
   `⚠ 미검증 — `으로 표시한다.
4. **병렬 에이전트를 4개씩 띄우지 않는다.** Plan 1에서 검색 할당량 소진,
   같은 파일 덮어쓰기, 에이전트 간 충돌이 발생했다. 순차 실행할 것.
5. **`seat4` 정의를 따른다** — `data/taxonomy.json`의 `_seat4Definition`.
