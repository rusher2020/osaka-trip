## 알려진 한계

- 구글 평점·리뷰수는 구글맵 직접 조회가 아니라 Wanderlog 스냅샷이다. 실시간 값과 다를 수 있고, f-02는 Plan 1 기록과 불일치한다(리스팅 중복 의심).
- 쇼핑 신규 12장의 `priceBand`는 브랜드 공식몰이 전부 차단돼 품목별 가격을 확인하지 못했다(PORTER 탱커 2점 제외). 전부 `⚠ 미검증`.
- 카드 112장 중 89장은 좌표 자동 대조가 불가능하다. 소규모 일본 식당·매장은 OpenStreetMap에 거의 등재돼 있지 않다. 2026-09-17 신규 카드 좌표는 국토지리원 주소검색 API 번지 지오코딩값이다. 이 카드들의 좌표는 조사 시점의 출처 페이지에 의존한다.
- 쇼핑 카드 18장의 영업시간·면세 카운터 정보는 실제 페이지로 확인되지 않았다. `caution`에 `⚠ 미검증`으로 표시돼 있다.
- 술 카드 3장(d-15·d-20·d-22)은 예산 상한 4,000엔을 넘는다. `bun run validate`가 경고로 알린다.
- `placeId`는 수집되지 않았다. Google API 키가 필요하며 대시보드 구현 단계로 미뤘다.
- 출발 1주 전(2026-10-30경) 영업시간·휴무 재확인이 필요하다.
